# Критерии готовности

Наш общий ответ на вопрос: **когда задачу разрешено перетащить в «Готово»?**

Этот файл меняется только через запрос на внесение изменений. Договорённость,
которую можно переписать молча, перестаёт быть договорённостью.

---

## Этап 1

Задача считается сделанной, если выполнено всё:

- [ ] Все условия приёмки из карточки выполнены и проверены руками или тестом
- [ ] Автоматические проверки проходят
- [ ] Покрытие тестами не упало
- [ ] Новое поведение закрыто тестом
- [ ] Напарник прочитал изменение и оставил хотя бы один содержательный комментарий
- [ ] Изменение внесено в основную ветку
- [ ] Документация обновлена, если менялось поведение или команды запуска
- [ ] Паролей, ключей и адресов серверов в изменениях нет
